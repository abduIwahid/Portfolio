Connect Four AI

A game-playing project focused on decision-making, search, and learning in a turn-based environment.

Project overview

Connect Four AI explores how an agent can select moves in a turn-based game. The project context includes adversarial search and reinforcement-learning approaches.

Topics explored

  • Representing the game state and legal moves.
  • Using minimax-style search with alpha-beta pruning to reduce explored branches.
  • Evaluating positions with a heuristic function when the full game tree is too large.
  • Exploring Q-learning as a learning-based approach.
  • Testing against human play and checking edge cases such as full columns and terminal states.

Evaluation

A meaningful evaluation should record win/draw/loss rates over repeated games and specify opponents, random seeds, and search settings. No performance claims are made here without recorded test results.
