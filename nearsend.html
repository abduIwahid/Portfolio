NearSend

A private file-sharing experience designed to make sending files between nearby devices straightforward.

Overview

NearSend is a browser-based file-sharing project focused on moving files between nearby devices without requiring an account or a cloud upload workflow.

Core ideas

  • Pair devices and initiate a transfer from a browser interface.
  • Use WebRTC for direct peer-to-peer data transfer when the connection can be established.
  • Use QR-based pairing and transfer progress feedback as part of the user experience.
  • Keep signaling separate from the file payload where the implementation supports direct transfer.

Technical considerations

Peer-to-peer connectivity depends on browser support, network conditions, NAT/firewall behavior, and signaling/STUN/TURN configuration. “Direct” transfer does not guarantee that every network connection will succeed.
