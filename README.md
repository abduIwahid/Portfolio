## 📖 About This Project

This is the source code for my **personal developer portfolio website**, live at [abdulwahid.me](https://www.abdulwahid.me). It serves as a central showcase of my skills, projects, experience, and education as a BS Artificial Intelligence student with a passion for Machine Learning, Python, and Software Engineering.

The portfolio is fully responsive, features smooth animations, and is built with pure **HTML, CSS, and JavaScript** — no frameworks, just clean, fast, handcrafted code.

---

## ✨ Features

- 🎨 **Modern Dark UI** with animated gradient accents
- 📱 **Fully Responsive** — optimized for mobile, tablet, and desktop
- ⚡ **Zero Dependencies** — pure HTML/CSS/JS, no frameworks
- 🔗 **Live GitHub Stats** — dynamic contribution graph and repository cards
- 🧭 **Smooth Navigation** — sticky navbar with active section tracking
- 📄 **Downloadable CV** — one-click CV download via Google Drive
- 📬 **Contact Section** — direct email, WhatsApp, and LinkedIn links
- 🌐 **SEO Optimized** — meta tags, OG tags, and structured content

## 🖥️ Local Development

No build tools or package managers required.

```bash
# Clone the repository
git clone https://github.com/abduIwahid/abdulwahid.git

# Open in browser
cd abdulwahid
open index.html
# or just drag index.html into your browser
```

To preview with live reload, use VS Code's **Live Server** extension.
